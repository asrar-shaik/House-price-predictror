# House-price-predictror
A Machine Learning-based web application that predicts house prices based on property-related inputs. The application also includes a map feature that allows users to navigate and explore the selected location.
Features

🏠 House price prediction
📊 Machine Learning-based prediction
🗺️ Interactive map/location navigation
💻 User-friendly interface
⚡ Real-time prediction

Technologies

Python
Pandas
NumPy
Machine Learning
Streamlit
Maps

Project Objective

The objective of this project is to build a practical Machine Learning application that can help users estimate property prices while providing location-based visualization.
